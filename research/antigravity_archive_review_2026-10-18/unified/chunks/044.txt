### Why `python -c` Failed

In Python 3.12, running code via `python -c "<string>"` sets `__file__ = None` and the module becomes `<module '__main__' (built-in)>`. 

When `multiprocessing.spawn` launches child workers for each TPU core, it runs:
`python -c "from multiprocessing.spawn import spawn_main; spawn_main(...)"`
The child worker looks for `check_core` in `__main__`. But because the parent code was an in-memory string and not a physical `.py` file on disk, the child process has no file to read and throws:
`AttributeError: Can't get attribute 'check_core' on <module '__main__' (<class '_frozen_importlib.BuiltinImporter'>)>`.

To use multiprocessing with `spawn`, the script must be a **real file on disk**.
