## 3. Paradigm Code Audits & Verifications

### 1. Autoregressive (AR) Pipeline
- **PyTorch Implementation** (telos/diffusion/ar.py):
  - Causal masking enforced in attention: `is_causal_override=True` delegates directly to PyTorch's fused FlashAttention-2 / SDPA kernel.
  - Chunked Cross-Entropy: On CUDA GPUs, slices CE into 4,096-token chunks to eliminate activation memory spikes without touching backward graph correctness.
  - PyTorch-XLA Guard: On TPU (`xla`), chunking is bypassed so XLA compiles cross-entropy into a single fused reduction kernel, avoiding HLO buffer re-padding.
  - Special Token Masking: Special tokens ($\le 3$) are excluded from causal loss via elementwise boolean masking.

- **MLX Implementation** (telos/diffusion/ar.py):
  - Fast SDPA: Uses `mx.fast.scaled_dot_product_attention(..., mask="causal")`.
  - RoPE: Hardware-accelerated `mx.fast.rope(..., traditional=True)`.
  - Content count normalization divides per-example cross-entropy by non-special token count.

### 2. Masked Diffusion (MDLM) & Uniform Noise Diffusion (UNDLM)
- **PyTorch Implementation** (telos/diffusion/mdlm.py & telos/diffusion/undlm.py):
  - Bidirectional Attention: `mask_override=False` disables causal masking so every position attends to all visible tokens.
  - MDLM: Samples continuous diffusion timestep $t \sim \text{Beta}(1.5, 1.5)$, masks tokens where $\text{rand} < t$, and computes $1/t$ reweighted variational lower bound loss.
  - Special Token Protection: Special tokens (PAD=0, MASK=1, BOS=2, EOS=3) are never masked, preventing corruption of structural delimiters.
  - Device-Resident Beta Buffer: Pre-allocates $1\text{M}$ samples on device to prevent per-microbatch CPU RNG bottlenecks.

- **MLX Implementation** (telos/diffusion/mdlm.py & telos/diffusion/undlm.py):
  - Vectorized `mx.where` token substitution.
  - Loss computation cast to `mx.float32` before log-softmax to eliminate numerical underflow.

### 3. COROSred Unified Continuous Training
- **PyTorch Implementation** (telos/diffusion/corosred_unified.py):
  - **Heterogeneous Microbatch Partitioning**: Splits microbatch $B$ into $B_c = \text{round}(B \times 0.75)$ causal sequences and $B_m = B - B_c$ infilling sequences.
  - **Zero Host-Sync LRH Metrics**: In inner microbatches, blocking `.item()` calls and double-argsort ROC-AUC calculations are bypassed in favor of the running EMA, keeping GPU/TPU command queues fully saturated.
  - **Per-Token Task Normalization**:
    $$\text{pooled\_task\_loss} = \frac{\alpha(t) \cdot \overline{\text{CE}}_c + \beta(t) \cdot \overline{\text{CE}}_m}{\max(10^{-6}, \alpha(t) + \beta(t))}$$
    Normalizes losses per evaluated token. Eliminates the former $20.16\times$ token count mismatch that previously suppressed infilling gradients.
  - **TPU Top-$k$ Ambiguity Filter**: Counts `(logits > target_logit).sum(-1) < k_amb` directly in tensor space, completely bypassing `torch.topk` sorting which previously caused TPU PJRT SIGSEGV.

- **MLX Implementation** (telos/diffusion/corosred.py):
  - Dual-slice forward pass: `batch_causal` executed with `mask_override="causal"` and `batch_infill` with `mask_override=False`.
  - Fused per-token task normalization matching PyTorch formulation.
