**Pass@1** is the industry-standard benchmark metric for code generation (introduced by OpenAI in the 2021 Codex / HumanEval paper).

---

### 1. The Exact Definition

> **Pass@1** means: The model gets **exactly 1 attempt** to write a complete function from scratch. If that single generated function passes **$100\%$ of the unit test assertions** in the sandbox without crashing, timing out, or raising a syntax error, it scores **$1$**. Otherwise, it scores **$0$**.

Formally, across a benchmark suite of $N$ coding problems:
$$\text{Pass@1} = \frac{\text{Number of problems where the 1st generated solution passes all unit tests}}{\text{Total number of problems}}$$

---

### 2. Why Pass@1 is Dramatically Harder than Top-1 Token Accuracy

| Metric | What It Measures | Difficulty | Example |
| :--- | :--- | :--- | :--- |
| **Top-1 Token Accuracy** | Did the model predict the **single next token** correctly? | **Local** ($60\% - 96\%$) | Given `x = 10; print([MASK])`, predicting `x`. |
| **Pass@1** | Did the model generate an **entire chain of 50–120 tokens** where **every single line of algorithmic logic** is $100\%$ bug-free across multiple unit tests? | **Combinatorial** ($0\% - 5\%$ for sub-300M models) | Writing the full Sieve of Eratosthenes algorithm from a docstring. |

#### The Exponential Math:
If an algorithm requires **50 sequential tokens**, and a model has an impressive **$95\%$ accuracy per token**:
$$0.95^{50} \approx 7.6\% \text{ chance of a completely bug-free program}$$

If even **one single token** is wrong (e.g. `<` instead of `<=`, returning `0` instead of `None`, or an off-by-one loop index), Python executes the test:

The test throws **`AssertionError`**, and the task receives **$0.0\%$**.
