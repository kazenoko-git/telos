# v1.8.7 validation

This release lands diffusion training, sampler, and interleaved COROSred decoding optimizations across PyTorch and MLX.

## Verified Locally (PyTorch CPU)

- **Masked-only infill LM head + CE (`telos/diffusion/corosred_unified.py`, `telos/models/transformer.py`):** Verified forward and backward gradient parity (`atol=1e-5`, exact `0.0` microbenchmark diff); measured **3.57×** LM-head+CE speedup (`5.28 -> 1.48 ms` at `B=3, T=256, D=512, V=8192, p=0.20`).
- **Zero-vocab-projection `reliability_scores()` (`telos/models/transformer.py`, `telos/diffusion/corosred_unified.py`):** Verified `RoutingMaskCache.refresh` never invokes `output_projection` and matches full forward bit-for-bit (`torch.equal`).
- **Vectorized interleaved COROSred probe (`telos/decoding/interleaved_corosred.py`):** Eliminated redundant `F.log_softmax` and `.clone()` (partition cancels in `log_p[alt] - log_p[orig] == logit[alt] - logit[orig]`); measured **4.01×** speedup at `V=8192` with exact `id_match`. Added tail-window stop checks, single-pass lexical token decoding, and prefix-truncated KV-cache rebuild.
- **`MDLMSampler` (`telos/diffusion/sampler.py`):** Masked-only softmax/topk, vectorized repetition penalty, and opt-in Fast-dLLM `confidence_threshold` / Prophet `early_commit_margin` verified on CPU.
- **COROSred Phase B/C & `DualMetricMonitor` (`telos/diffusion/corosred.py`, `telos/training/monitor.py`):** Removed per-microbatch `torch.clear_autocast_cache()`, replaced `torch.argsort` with `torch.topk`, and enabled `next_token_only=True`.

## Verified on Apple M5 Pro (`applegpu_g17s`, MLX 0.32.2)

Full test suite passed (`486 passed, 7 skipped` via `.venv/bin/python -m pytest -q`) and benchmarks via `scratch/bench_v186_v188_m5pro.py` recorded:

- **`MLXTelosTransformer.reliability_scores()` (`B=4, S=256, d_model=512, n_layers=6, V=8192`):** Exact `0.0` max abs diff vs `model(x, return_reliability=True)[1]`; `3.156 ms` vs `3.141 ms` (`156.77 MB` peak), confirming MLX's lazy graph already prunes un-evaluated logits when only the reliability tensor is materialized (while `reliability_scores()` avoids building the projection graph and directly accelerates eager PyTorch).
- **`MLXMDLMSampler` on-device `mx.topk` (`seq_len=128, num_steps=32, d_model=512, n_layers=6, V=8192`):**
  - Default cosine schedule: **50.729 ms** (**2,365.5 gen tok/s**), **93.74 MB** peak GPU memory.
  - Fast-dLLM `confidence_threshold=0.7`: **48.051 ms** (**2,497.3 gen tok/s**), **93.74 MB** peak GPU memory (on untrained random weights; trained checkpoints with sharper distributions trigger early unmasking more aggressively).
  - Prophet `early_commit_margin=0.25`: **53.044 ms** (**2,262.3 gen tok/s**), **93.74 MB** peak GPU memory.
- **`corosred_unified_loss_fn_mlx` (`mask_blend` gating, `next_token_only=True`, `mx.partition`):** Verified under full M5 Pro pytest suite.
