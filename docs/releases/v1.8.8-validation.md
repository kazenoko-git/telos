# v1.8.8 validation

This release lands SFT, DPO, GRPO, and LoRA/QLoRA post-training optimizations across PyTorch and MLX.

## Verified Locally (PyTorch CPU)

- **Sparse valid-only `_torch_token_logps` without FP32 `log_softmax` (`telos/posttrain/trainer.py`):** Projects only `labels[:, 1:] != -100` hidden states through `output_projection` and uses fused `-F.cross_entropy(..., reduction="none")`. Verified exact forward and backward gradient parity (`atol=1e-5`) against full `log_softmax` + `gather`.
- **Zero-copy LoRA/QLoRA frozen base reference (`telos/posttrain/adapters.py`, `telos/posttrain/mlx_adapters.py`, `telos/posttrain/trainer.py`):** `disable_lora_adapters` evaluates the frozen base model without `copy.deepcopy(model)` in DPO/GRPO, verified bit-for-bit (`torch.equal`) against an unadapted base copy and full post-training resume tests.
- **GRPO zero-variance group skip (`telos/posttrain/trainer.py`):** Skips redundant `policy_updates` when `beta == 0` and all group advantages are zero (`uniform == 1.0`).
- **Portable `NF4Linear.dequantize()` (`telos/posttrain/adapters.py`):** Uses `int32` indices instead of `int64` to halve transient dequantization index memory; verified shape and finiteness on CPU.
- **CUDA post-training TF32/benchmark (`telos/posttrain/trainer.py`):** Enables `allow_tf32` and `cudnn.benchmark` on CUDA.

## Verified on Apple M5 Pro (`applegpu_g17s`, MLX 0.32.2)

Full test suite passed (`486 passed, 7 skipped` via `.venv/bin/python -m pytest -q`, including MLX QLoRA GRPO rollout/resume parity) and benchmarks via `scratch/bench_v186_v188_m5pro.py` recorded:

- **Zero-copy MLX QLoRA base reference (`disable_lora_adapters` vs `copy.deepcopy`, `B=4, S=256, d_model=512, n_layers=8, V=8192`):**
  - **Active model memory:** **35.68 MB** vs `70.18 MB` (**-49.2%**, saving `34.50 MB`).
  - **Peak GPU memory:** **363.55 MB** vs `569.05 MB` (**-36.1%**, saving `205.50 MB`).
  - **Reference forward latency:** **16.033 ms** vs `19.802 ms` (**1.24×** faster, skipping adapter matmuls on the reference pass).
  - **Output parity:** **`0.0`** max abs diff against a frozen `deepcopy` base reference.
