# v1.7.5 preparation — 2026-11-16

Based on v1.7.4 (`61e2b61`), retaining its memory planner and exact-divisor
accumulation behavior. This work corrects the opt-in MLX vocabulary-tiled CE
and adds a default-off token-chunked projection/CE prototype. No MLX runtime,
QKV, buffer-setting or attention-backward default changes.

## Correctness

The unchanged historical tiled method reproduces a negative BF16 CE and a
missing confident-target gradient. Both are corrected by matching target and
partition rounding and using a direct FP32 CE logits backward. AR retains the
same full transformer context as the reference projection path.

Focused coverage checks FP32/BF16 losses and first-order gradients, masks,
checkpointing, irregular tile sizes, positive/negative/zero cotangents,
argument contracts and exact checkpoint replay for each chunk axis. A CLI
regression prevents silent use of the MLX-only token option on PyTorch.

The final full repository suite passed **379 tests with 7 skipped** on MLX
0.32.2. Before the final CLI guard, it also passed **378 tests with 7 skipped**
with isolated MLX 0.32.4 in the parent process.
Some existing subprocess tests set their own runtime paths; this does not
establish that every subprocess used 0.32.4. The final guard's focused file
passed **25 tests** on 0.32.2. GPU tests use the local Metal device; mocked/CPU
checks do not establish physical CUDA or TPU behavior.

## Packaging

`uv build` generated the v1.7.5 wheel and source archive. The wheel was installed
into an isolated target, then imported from outside the checkout to verify the
version and actual package path. All **46 focused projection/loss checks**
passed against that installed wheel on MLX 0.32.2. The source archive contains
this document and the investigation report/evidence, with corpus binaries and
training checkpoint tensors excluded. The shared Python environment was not
upgraded or replaced.

## Performance limits

See the [complete investigation](../../reports/mlx_fusion_2026-11-16/REPORT.md).
The measured chunked head paths used more memory and ran slower than the full
projection. They remain experimental, and changed GEMM reduction order can
change BF16 gradients and weights. First-order replay within either chunked
path passes; bitwise equivalence to the full-head training run is not claimed.

The 24-shape same-runtime attention probe passed numerical/graph checks and
found a shape-dependent crossover. Its full-model confirmation hit a swap
guard, so automatic dispatch is deferred. Four completed 192-update QKV/buffer
runs matched all final model/master/optimizer/MLX RNG tensors exactly. Buffers
16/16 reduced allocation; incomplete reverse-order repeats prevent a new
speedup claim.

This document prepares v1.7.5; it does not assert that a tag, GitHub Release or
PyPI distribution has been published.
