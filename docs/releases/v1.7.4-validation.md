## Limits and earlier performance evidence

The memory planner estimates peak training storage and reserves at least 1 GiB
inside a ceiling of 60% system RAM (or a smaller device/configured cap). It does
not calculate an exact universal maximum; MLX allocation limits are advisory.
Explicit checkpointing-off is retained. If the model cannot fit even at the
smallest permitted microbatch, startup fails rather than claiming accumulation
can shrink model/optimizer state. See [the policy](../mlx-memory-planning.md).

No new training-throughput or large-model peak-memory gain is claimed here.
The merged [pretraining investigation](../../reports/mlx_pretrain_2026-11-16/REPORT.md)
contains workload-specific prior runtime comparisons and their limits. The
separate accumulation=1 prototype is not included in this release.

The original dirty checkout and unrelated fusion experiments are preserved.
