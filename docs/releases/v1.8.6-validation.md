# v1.8.6 validation

This release lands pretraining structural and kernel optimizations across PyTorch/CUDA/XLA and MLX.

## Verified Locally (PyTorch CPU)

- **Token-chunked checkpointed CE (`telos/models/vocab_loss.py`):** Exact forward/backward parity (`atol=1e-6`) against native `F.cross_entropy`; measured **1.31×** forward speedup (`19.88 -> 15.15 ms` at `N=2040, D=512, V=8192`) vs 256-vocab tiling.
- **Single-sort ROC-AUC (`telos/training/schedule.py`):** **0.0** diff vs double-argsort reference; measured **2.18×** speedup (`0.132 -> 0.061 ms` at `N=4096`).
- **Hoisted XLA checkpoint import (`telos/models/transformer.py`) & microbatch cadence invariants (`telos/training/trainer_pytorch.py`):** Verified via unit and structural regression tests.
- **Opt-in `CautiousAdamW` (`telos/training/cautious_optimizer.py`):** Verified loss decrease and `state_dict` round-trip on CPU (`training.cautious_optimizer: true`, default off).
- **Eliminated candidate:** PyTorch half-slice RoPE measured **0.89×** regression on CPU due to non-contiguous half-slice strides and was dropped.

## Verified on Apple M5 Pro (`applegpu_g17s`, MLX 0.32.2)

Full test suite passed (`486 passed, 7 skipped` via `.venv/bin/python -m pytest -q`) and ABBA benchmarks via `scratch/bench_v186_v188_m5pro.py` recorded:

- **Row-per-threadgroup Metal CE backward (`telos/training/mlx_losses.py`, `rows=2040, vocab=8192`):**
  - **BF16:** **0.689 ms** vs `4.522 ms` built-in (**6.56×** faster), peak GPU memory **63.77 MB** vs `318.78 MB` (**-80.0%**), `0.0` loss abs diff.
  - **FP32:** **1.006 ms** vs `3.437 ms` built-in (**3.42×** faster), peak GPU memory **191.28 MB** vs `318.79 MB` (**-40.0%**), `0.0` loss abs diff.
- **Register-hoisted M5 MPP fused projection CE backward (`telos/training/mlx_fused_projection.py`, `rows=2040, d_model=512, vocab=8192`, stays within 32 KiB threadgroup cap):**
  - **BF16:** **6.115 ms** vs `6.928 ms` dense (**1.13×** faster), peak GPU memory **41.04 MB** vs `346.75 MB` (**-88.2%**), `0.0` loss abs diff.
  - **FP32:** **14.018 ms** vs `13.018 ms` dense (`0.93×` compute-vs-memory tradeoff), peak GPU memory **114.78 MB** vs `368.76 MB` (**-68.9%**), `0.0` loss abs diff.
- **50M-class BF16 AR step (`B=4, S=512, d_model=512, n_layers=8, V=8192, chunk_axis="metal"`):** **49.219 ms/step** (**41,528.7 tok/s**), **1,322.19 MB** peak GPU memory.
- **Hoisted BF16 scale cast in `clip_grad_norm_mlx` (`telos/training/core.py`) & precomputed attention scale (`telos/models/mlx_components.py`):** Verified under full M5 Pro pytest suite.
