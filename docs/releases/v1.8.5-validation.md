# v1.8.5 validation

This release layers persistent XLA compilation cache configuration, native XLA activation checkpoint dispatch, deterministic AR RNG handling, and COROSred reduction ordering onto reconciled v1.8.4.

XLA call order and dispatch are checked using mocks. New behavior has not been validated on physical TPU hardware; no compilation-count or throughput improvement is claimed. Prior v1.8.2 physical TPU/CUDA evidence is retained with its original scope in `v1.8.2-validation.md`.

The release history preserves published remote features and validation, skips patch-equivalent local commits, and gives each of v1.8.3, v1.8.4 and v1.8.5 matching package metadata and cumulative changes.
