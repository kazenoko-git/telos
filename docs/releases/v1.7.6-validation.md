# v1.7.6 validation — 2026-11-17

MLX pretraining now enables bounded asynchronous gradient accumulation by default.
Disable with `--no-async-accumulation` or `training.async_accumulation: false`.
The step wrapper and core helper share this default. Accumulation of one does not
use the accumulation pipeline. Eager memory policy and stage profiling disable
it, and each accumulated update completes optimizer state before returning.
Compiled accumulation remains a separate opt-in. Other backends are unchanged.

## Evidence and release decision

The [randomized thermal/clock follow-up](../../reports/mlx_clock_controlled_2026-11-17.md)
completed two complementary 1,536-update replays. Async delivered 39,047 versus
37,191 input tok/s (+4.99%), winning 41/44 adjacent pairs. Saved model, optimizer,
master-weight and MLX RNG arrays matched exactly. The ten strict matched pairs
favored async by 5.46%, but missed the planned coverage minimum. GPU clocks were
observed, not locked. This measures a workload switching between modes; it does
not establish 100%-async sustained thermal behavior or general gains.

The earlier [separate-process comparison](../../reports/mlx_async_sustained_2026-11-17.md)
measured a clock-confounded −3.97% pooled async result. Both findings are retained.
The release decision accepts these limits and enables the bounded path with an
explicit synchronous override. This is not a claim of universal speedup.

## Checkpoint fix

The recursive MLX state encoder previously retained its array accumulator until
cyclic garbage collection. Passing it explicitly removes that retention cycle
without changing the checkpoint format. A regression verifies tensor release
with cyclic GC disabled and exact nested-state round-trip. The long comparison
used the old frozen serializer; it does not measure sustained performance after
this fix. See the follow-up report for the shared update-1,000 allocation jump.

## Checks

The full local suite passed **399 tests, 7 skipped** after the default change.
Coverage includes default async dispatch, explicit synchronous opt-out, bounded
queue depth, eager-policy fences, FP32/BF16 master updates, compiled/uncompiled
accumulation and MLX RNG state comparisons. Experimental comparison wrappers
explicitly retain their independent synchronous baseline.

Release packaging is checked from a clean committed export, preserving unrelated
working-tree changes. The wheel and source archive include the version and
validation evidence, with checkpoint tensors and corpus binaries excluded.
Physical CUDA/TPU training and other MLX hardware/workloads were not rerun.
