# Current comparison audit

14 November 2026. Saved responses, scorer, adapters, generator, summaries, HTML payload, and rendered PNG checked. No inference in this audit. Source fingerprints and case-level findings are in independent_audit_current.json; reproduce with audit_current_comparison.py. Files were being updated concurrently: the initial merged Qwen 2B snapshot had 71 records; the final audited snapshot and dashboard had 512.

## Findings

- **Qwen 0.8B: completed attempts, incomplete capability coverage.** The 512 records contain 282 correct, 172 incorrect, 53 HTTP 500 server errors, and five malformed/truncated generations. All 43 percentage cases and ten scalar cases returned HTTP 500. The recorded 282/512 (55.08%) is an end-to-end attempt success score, not clean accuracy over successfully served tasks. Preserve it and label retries separately. Do not discard errors and compare the remaining categories as a matched full suite.
- **Qwen 2B: output contract dominates failures. Excluded from report at user's request.** All 362 incorrect-answer records have object-valued answers on non-money tasks. Of those, 76 have a single field whose normalized value matches gold. These are diagnostic candidates, not automatically awarded points. Example arithmetic-01 returns {total_tasks:19}, with correct arithmetic in the reason; arithmetic-02 returns {amount:9,currency:""}. Twenty-one other generations are truncated JSON. The schema allows an object on every task rather than restricting the shape by requested type. A future run should use task-specific schemas; preserve this raw run and do not publish its number as a model capability ranking.
- **Malformed JSON still has the wrong outcome label.** Adapters return error.kind=malformed_response with status MALFORMED; classify_outcome checks error first and falls through to transport_error. All five Qwen 0.8B truncations and all 21 Qwen 2B truncations receive that wrong category. This also affects local baseline truncations. Reclassifying these does not improve answer correctness.
- **Primary score does not require evidence.** The classifier checks status/value only. Correct records with missing answer evidence: Bonsai 9, LFM 23, Ministral 11. Correct records with invalid quote offsets: Bonsai 40, LFM 19, Ministral 24, Qwen 0.8B 74. These counts can overlap. Reader and Gemma have zero in both checks. Retain a clearly named status/value score and add a separate grounded score if evidence is a claimed acceptance condition. Offset validity alone does not establish that a quote supports the answer; empty evidence passes offset validity vacuously.
- **Gemini remains incomplete, with stale prose counts.** Final source snapshot has 207 attempted IDs: 107 non-error responses (106 correct), 100 quota errors, and 305 unattempted IDs. Sixteen errors retain the old transport_error classification. Figure notes and findings still say 132 attempts, 25 quota errors, 380 unattempted. Excluding Gemini from the full-suite ranking is correct; derive counts from the source instead of hardcoding them.
- **Latency comparison mixes layers.** Reader's ~293ms is provider-reported while its client median is ~1009ms; LM Studio latency is measured at the client. Figure's single response-latency axis uses these mixed measurements. Use client duration for comparative response latency, separately display provider/executor time, and disclose failures omitted from latency samples. Example Qwen 0.8B model median 631.9ms versus client median 603.03ms reflects different error inclusion, not physically faster network delivery.
- **Confidence is not calibrated or validated.** Qwen 0.8B has 238 values outside [0,1], Ministral 148, Bonsai one. Do not rank reliability or plot these as probabilities without an explicit scale contract and validation.
- **Figure needs layout and data corrections.** Direct PNG inspection shows overlapping log-axis ticks, overlapping/clipped diagnostic callouts, Qwen 0.8B at the lower plot edge, and no completed 2B row (now deliberately excluded). Its diagnostics include unsupported statements: Gemma arithmetic is 40/43 (93%), not 95%; LFM missing is 31/43, not 100%. Callout statistics remain hardcoded. Replace with concise data-derived content and inspect the rendered output.
- **Model identity and run configuration remain underdocumented.** Raw API model labels are retained, but friendly checkpoint/quantization/architecture strings in the dashboard are manually assigned. They do not prove checkpoint bytes, exact quantization, thinking mode, hardware/power mode, or equivalent tuning. Local max_tokens=256, LFM max_tokens=200; preserve these as measured settings rather than claiming architecture-level superiority.
- **Retry accounting remains incomplete for Gemini.** Its adapter retries internally, then the runner retries. Inner HTTP attempts are not returned individually. Saved first_attempt/retries cannot establish true first-request success or complete per-attempt cost/latency.

## Checks passed

- 512 unique gold IDs. Regenerating the current suite in memory reproduces every saved case exactly. This checks reproducibility, not an independent oracle for every gold answer.
- All completed full-suite models have 512 unique known IDs. Every saved correctness decision agrees with the current scorer; no evidence-grade mismatches found.
- Re-parsing retained successful general-model raw outputs and applying current normalization reproduces stored values.
- Full local baseline counts remain Ministral 466, Gemma 431, LFM 430, Bonsai 412 out of 512; Reader 330/512. No headline score correction was silently applied.
- Money normalization no longer defaults missing currency to USD, including bare number inputs. The local schema permits the required money objects.
- Reader retains 128/128 recorded sampled replay matches; these establish executor consistency, not correctness of selected operands or every answer.
- The original v1 artifact remains separately archived. No original inference records were overwritten by the audit.

## Publication boundary

Use status/value correctness as the named metric, separate evidence and client/provider latency, omit Qwen 2B, and label the Qwen 0.8B rerun as error recovery. Gemini stays outside the full-suite ranking. Parameterized synthetic diagnostics do not establish general-document accuracy or statistical independence of 512 tasks. The 272-case subset has already informed repairs, so it is no longer an untouched final test for future iterations. Full semantic evidence entailment, every gold answer, runtime identity, and interactive browser behavior were not independently certified here.
